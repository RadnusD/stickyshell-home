## 1. Hacker News ("Show HN")

**Submit URL**: [https://news.ycombinator.com/submit](https://news.ycombinator.com/submit)

**Title**: 
`Show HN: StickyShell – Desktop sticky note with instant shell execution`

**Text Body**:
```markdown
Hi HN! I built StickyShell because I frequently found myself copying terminal commands, scripts, and diagnostic snippets between random browser tabs, notes, and terminal windows.

StickyShell Home is a lightweight desktop sticky note built with Tauri v2 and Rust that lets you execute commands right inside your note:
- Multi-Line Block Execution: Run commands or multi-line shell scripts directly from your note.
- Inline Capture Mode (Ctrl+Enter): Runs commands and captures output into a slide-out drawer with 1-click copy.
- External Console Mode (Ctrl+Shift+Enter): Opens an interactive system console for longer interactive tasks.
- 100% Offline: Zero telemetry, no cloud sync, and all notes stored in local JSON.

Cross-platform binaries (Windows .exe/.msi, macOS Universal .dmg, Linux .AppImage/.deb/.rpm) are available:
https://github.com/RadnusD/stickyshell-home/releases/tag/v1.1.0

Repository: https://github.com/RadnusD/stickyshell-home

Feedback and suggestions welcome!
```

`[Release] StickyShell Home v1.1.0 – A lightweight desktop sticky note that executes shell commands`

**Post Body**:
```markdown
Hey everyone!

I just released v1.1.0 of StickyShell Home, a cross-platform desktop sticky note app designed as a command-line scratchpad.

Key Features:
- Multi-Line Block Execution: Execute scripts and multi-line commands directly from notes.
- Dual Execution Modes: Inline output drawer (Ctrl+Enter) or external terminal console (Ctrl+Shift+Enter).
- Always on Top & Global Hotkeys: Floating pin toggle, plus Win+Alt+S (toggle all) and Win+Alt+N (new note).
- Markdown & KaTeX Math: Instant LaTeX math and checklist formatting.
- 100% Offline & Private: Zero accounts, zero tracking, zero remote telemetry.

Built with Tauri v2 + Rust for sub-millisecond responsiveness.

GitHub Release & Downloads (Windows / macOS / Linux):
https://github.com/RadnusD/stickyshell-home/releases/tag/v1.1.0
```
