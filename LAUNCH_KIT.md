**Submit URL**: [https://news.ycombinator.com/submit](https://news.ycombinator.com/submit)

**Title**: 
`Show HN: StickyShell – Desktop sticky note with instant terminal command execution`

**Text Body**:
```markdown
Hi HN! I built StickyShell because I frequently found myself copying terminal commands, one-liners, and diagnostic snippets between random browser tabs, sticky notes, and terminal windows.

StickyShell Home is a lightweight desktop sticky note built with Tauri v2 and Rust that lets you execute commands right inside your note:
- Inline Capture Mode (`Ctrl+Enter`): Runs the command and captures output into a slide-out drawer with 1-click copy.
- External Console Mode (`Ctrl+Shift+Enter`): Opens an interactive system console for longer interactive tasks.
- Persistent Undo Buffer (`Ctrl+Z`): Restores closed or deleted notes even after app restart.
- 100% Offline: Zero telemetry, no cloud sync, and all notes stored in local JSON.

Cross-platform binaries (Windows .exe/.msi, macOS Universal .dmg, Linux .AppImage/.deb/.rpm) are available:
https://github.com/RadnusD/stickyshell-home/releases/tag/v1.0.0

Repository: https://github.com/RadnusD/stickyshell-home

Feedback and suggestions welcome!
```

**Post Body**:
```markdown
Hey everyone!

I just released v1.0.0 of **StickyShell Home**, a cross-platform desktop sticky note app designed to act as an instant command-line scratchpad.

### 🌟 Key Features:
- ⚡ **Dual Execution Modes**: Inline Output drawer (`Ctrl+Enter`) or External Console (`Ctrl+Shift+Enter`).
- 📌 **Always on Top & Global Hotkeys**: Floating pin toggle, plus `Win+Alt+S` (toggle all) and `Win+Alt+N` (new note).
- 🛡️ **Accidental Delete Protection**: Full persistent `Ctrl+Z` undo stack across restarts.
- 📐 **Markdown & KaTeX Math**: Instant LaTeX math and checklist formatting.
- 🔒 **100% Offline & Private**: Zero accounts, zero tracking, zero remote telemetry.

Built with Tauri v2 + Rust for sub-millisecond responsiveness and a tiny installer size (~3.2 MB).
```
