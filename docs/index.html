Dual Execution Modes

Run commands in Inline Capture (Ctrl+Enter) mode with a slide-out drawer, or pop open an interactive External Console (Ctrl+Shift+Enter).

🛡️

Persistent Undo Buffer

Accidentally closed a note? Press Ctrl+Z to instantly restore your deleted notes and commands, even after closing the app.

🔒

100% Offline & Private

Zero telemetry, zero cloud tracking, zero accounts. All notes and settings remain strictly on your local hard drive in standard JSON.

📌

Always on Top & Global Hotkeys

Pin notes to float above your active workspace. Toggle all notes instantly with Win + Alt + S or spawn a new note with Win + Alt + N.

📐

Markdown & KaTeX Math

Write formatted notes, task checklists, and complex mathematical formulas with built-in instant LaTeX rendering.

Sub-Millisecond Speed

Powered by Tauri v2 and Rust. Uses negligible memory, launches instantly, and consumes practically zero background CPU.

Keyboard Shortcuts

Control StickyShell without ever leaving your keyboard.

Shortcut Action
Win + Alt + S Toggle (Show / Hide) all open sticky notes
Win + Alt + N Create a new sticky note
Ctrl + Enter Execute command (Inline Capture Mode)
Ctrl + Shift + Enter Execute command (External System Console)
Ctrl + Z Undo delete (Restores closed note)
