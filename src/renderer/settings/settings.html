StickyShell Controls & Header UI Layout

Visual map and functional reference for all controls and shortcuts:

▶

Run Command Execution

Menu Item

Execute shell commands directly in your chosen terminal.

  • Click Run in 3-dot menu (or press Ctrl+Enter): Instant execution
  • Click Run Options: Opens folder & terminal picker flyout
  • Dual Execution: Run inline console drawer or launch external terminal
＋

New Note

Header Item

Spawns an independent, frameless sticky note with its own working folder and persistent undo buffer.

  • Shortcut: ＋ button or tray menu
  • Restored automatically upon next system restart

Pin to Top (Always on Top)

Header Item

Pins the current sticky note above all other operating system windows.

  • Visual Indicator: Turns vibrant red when active
  • State is saved automatically per note

Delete Note & Undo Buffer

Header Item

Closes and moves the note to the safe Undo Buffer with confirmation safety.

  • Undo: Open 3-dot menu and click Undo Delete
  • Permanent deletion only when cleared
⋮

Three-Dot Context Menu

Header Item

Access notes management, undo buffer, settings, and application controls.

✕

Close Window

Header Item

Hides the note while keeping StickyShell active in the system tray.

  • Zero data loss: content is auto-saved before closing
  • Re-open anytime from the Windows Taskbar Notification area
⚡

System Tray Notification Area

Taskbar Notification Tray

StickyShell runs silently in the background.

  • Right-click tray: Restore all notes, New note, Settings, Exit
  • Left-click tray: Instantly summon or hide all sticky notes
