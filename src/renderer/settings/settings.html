Execution Features & Superpowers

Highlight-to-Run (Selective Execution)

Editor Feature

Highlight any line or code block inside your note and press Ctrl + Enter (or click Run). StickyShell executes only that selection. When nothing is selected, the whole note executes.

Multiline Script Execution

Terminal Feature

Multi-line PowerShell loops, batch scripts, and Bash scripts execute as complete cohesive scripts without line-by-line syntax errors. Console windows show a clean title without leaking temp paths.

LaTeX Math & Markdown Preview

Preview Feature

KaTeX engine rendering is built in. Write inline math like $E=mc^2$ or display blocks like $$\sum_{i=1}^n i$$. Press Ctrl + P or double-click to toggle preview.

Per-Note Working Directory

System Feature

Bind individual notes to specific project directories. Click Menu > Run Options and pick any folder. Commands executed from that note run directly inside that target directory.

Always-on-Top Pinning

Window Feature

Click the pin icon in the note header. When active, it turns vibrant red and floats above all full-screen windows, browsers, editors, and games. Pin state persists per note.

Persistent Note Recovery Buffer

Storage Feature

Accidentally closed or deleted a note? Closed notes are kept safe in the SQLite recovery buffer. Click Menu > Undo Delete at any time (even after restarting the app) to restore the note.

Sticky Note Controls Reference

New Note

Header Bar

Spawns an independent, frameless sticky note with its own working folder, auto-save state, and execution history.

Delete Note

Header Bar

Closes and archives the note into the safe recovery buffer. Restorable anytime via Menu > Undo Delete.

Three-Dot Menu

Header Bar

Access Run, Run Options (terminal picker & working directory), Undo Delete, Settings, and application controls.

Close Window (Hide to Tray)

Header Bar

Hides the note to the system tray without data loss. Content is auto-saved before hiding.

System Tray Area

Taskbar Notification

StickyShell runs in background. Left-click to summon/hide notes; right-click for quick actions, new note, settings, or exit.
