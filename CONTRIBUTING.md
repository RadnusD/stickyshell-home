# Feedback and Support Guidelines

Thank you for using StickyShell Home. We welcome bug reports, user feedback, and feature suggestions to improve the application.

---

## Reporting Bugs

Before reporting a bug, check existing issues to see if it has already been reported.

When opening an issue, use our [Bug Report Form](https://github.com/RadnusD/stickyshell-home/issues/new?template=bug_report.yml) and include:
- Operating System: Windows (10/11), macOS (Apple Silicon / Intel), or Linux.
- StickyShell Version: e.g. 1.1.0.
- Reproduction Steps: What you did and what happened.
- System Diagnostics: The output from the Copy Diagnostics button in Settings -> About.

---

## Proposing Features

Have an idea for StickyShell? Open a [Feature Request Form](https://github.com/RadnusD/stickyshell-home/issues/new?template=feature_request.yml) explaining:
- The problem or workflow you are trying to address.
- Your proposed solution or capability.
- Any alternative workflows you have tried.

---

## Releases and Downloads

Official cross-platform packages are available on the [Releases Page](https://github.com/RadnusD/stickyshell-home/releases).
